# Active Directory Basics

## 🧠 Room Overview
This room introduced the fundamentals of **Active Directory (AD)** and how it is used to manage users, groups, computers, and policies in a Windows enterprise environment.

---

## 🎯 What I Learned

- What Active Directory is
- The role of a **Domain Controller**
- Users, Groups, Computers, and Organizational Units (OUs)
- **Kerberos** authentication basics
- How **Group Policy** is used in enterprise networks

---

## 🛠️ Skills Practiced

- Identifying core AD components
- Understanding domain structure
- Recognizing centralized authentication and authorization
- Exploring permission and policy management

---

## 📌 Why It Matters

Active Directory is one of the most important technologies in enterprise cybersecurity. Understanding AD is essential for:

- SOC operations
- Incident response
- System administration
- Penetration testing
- Identity and access management
