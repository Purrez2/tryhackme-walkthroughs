## Overview

The **Networking Concepts** room introduced the fundamental principles of computer networking and how devices communicate across networks. It covered IP addressing, network devices, common protocols, ports, and the OSI/TCP-IP models. These concepts provide a strong foundation for understanding network security, packet analysis, and penetration testing.

---

## What I Learned

### What is a Network?

- A network is a collection of connected devices that communicate and share resources.
- Learned the difference between **Local Area Networks (LAN)** and **Wide Area Networks (WAN)**.
- Understood that the Internet is the world's largest network.

### Network Devices

- Learned the purpose of routers, switches, hubs, and access points.
- Understood how these devices direct and manage network traffic.

### IP Addresses

- Every device connected to a network requires an IP address.
- Learned the difference between **public** and **private** IP addresses.
- Gained an introduction to IPv4 addressing.

### Common Networking Protocols

| Protocol | Purpose |
|----------|---------|
| HTTP / HTTPS | Web browsing |
| FTP | File transfer |
| SSH | Secure remote access |
| DNS | Converts domain names into IP addresses |
| DHCP | Automatically assigns IP addresses |

### OSI & TCP/IP Models

- Explored the seven layers of the OSI Model.
- Learned how the TCP/IP Model is used in modern networking.
- Understood how data moves through different networking layers.

### Ports and Services

| Port | Service |
|------|---------|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |
